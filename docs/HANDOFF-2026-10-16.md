## Archive D1/R2 : travail en cours, non prêt à déployer

- `migrations/0001_images.sql` : SQLite D1, métadonnées, SHA-256, propriétaire, clé R2, dimensions, date et JSON d'analyse.
- `worker/auth.js` : validation cryptographique JWT Cloudflare Access (signature RS256, issuer, audience), pas simple confiance dans un email en en-tête.
- `worker/images.js` : session, liste paginée, POST explicite, lecture privée de fichier et suppression. Isolation par `owner_sub`, requêtes SQL paramétrées, vérification Origin sur mutations, fichiers <=8 Mio JPEG/PNG/WebP, rollback R2 si insertion D1 échoue, réponses privées no-store.
- `worker/index.js` : API `/api/*`, autres requêtes vers assets. API 503 tant que D1/R2/Access ne sont pas configurés.
- `src/archive.js`, modifications `src/app.js` / HTML / CSS : bouton d'enregistrement explicite du canvas JPEG et analyse éventuelle, liste, reprise et suppression. Aucun POST automatique. **Cette interface n'a pas encore été testée dans le navigateur.**
- `wrangler.jsonc` a maintenant `main: worker/index.js`, binding assets `ASSETS` et priorité worker `/api/*`. **Bindings DB/IMAGES et variables Access non configurés** : ressources distantes non créées.
- Dépendance jose 6.1.0 ajoutée.
- `tests/archive.test.js` : JWT testé avec clés de test et JWKS intercepté, puis vrais D1/R2 locaux dans Miniflare.
