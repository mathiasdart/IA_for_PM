UNE IA QUI CONNAÎT SES LIMITES

Une aide au contrôle,
avec les réserves nécessaires.

L’audit porte sur une seule vue. Il ne constitue pas un inventaire complet de la salle.

Ce qui est visible

Chaises, tables via « dining table », portables et écrans via « tv ». Les tableaux et fenêtres ne sont pas pris en charge.

Le mobilier, uniquement

Cadrez une salle vide. Le modèle générique traite l’image entière ; seules les classes d’équipements sont exploitées. Aucun résultat sur les personnes. Aucun envoi pour l’analyse ; archivage facultatif sur demande.

Le dernier mot reste humain

Vérifiez les angles morts et les erreurs possibles. Les écarts signalent des points de contrôle, jamais une absence certaine.
